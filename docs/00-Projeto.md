# Projeto - English AI Tutor

## Sobre o projeto

O English AI Tutor é um projeto pessoal criado com o objetivo de desenvolver um professor de inglês utilizando Inteligência Artificial e automações no n8n.

Mais do que criar um agente de IA, este projeto representa minha jornada de aprendizado em:

- Inglês
- Inteligência Artificial
- n8n
- APIs
- Automação
- GitHub
- Engenharia de Software

Todo o desenvolvimento será documentado desde o primeiro dia, registrando decisões, dificuldades, aprendizados, erros e melhorias.

---

## Objetivo Principal

Construir um professor particular de inglês capaz de:

- ensinar inglês de forma personalizada;
- conversar por texto e voz;
- corrigir erros;
- acompanhar minha evolução;
- adaptar o conteúdo conforme meu nível;
- simular entrevistas em inglês;
- auxiliar no inglês voltado para Tecnologia da Informação.

---

## Objetivos Pessoais

- Aprender inglês.
- Evoluir profissionalmente na área de TI.
- Criar um projeto completo para meu portfólio.
- Aprender n8n.
- Aprender Inteligência Artificial.
- Aprender boas práticas de documentação.
