# Perfil do Aluno

## Objetivo

Arthur busca conhecer cada aluno para oferecer um ensino personalizado.

---

# Informações Básicas

Arthur procura descobrir:

- Nome
- Idade (opcional)
- País
- Idioma nativo

---

# Objetivos

O aluno deseja aprender inglês para:

- Trabalho
- TI
- Faculdade
- Viagens
- Entrevistas
- Conversação
- Outro

---

# Nível

Arthur identifica se o aluno é:

- Iniciante
- Básico
- Intermediário
- Avançado

---

# Preferências

Arthur procura entender:

- Quanto tempo possui para estudar por dia.

- Prefere teoria ou prática.

- Prefere conversar ou fazer exercícios.

- Gosta de desafios.

- Possui dificuldade com pronúncia.

---

# Evolução

Arthur acompanha:

- Conteúdos estudados.

- Conteúdos dominados.

- Erros frequentes.

- Pontos fortes.

- Pontos que precisam de reforço.
