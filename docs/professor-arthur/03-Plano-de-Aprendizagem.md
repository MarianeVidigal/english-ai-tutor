# Plano de Aprendizagem

## Objetivo

Este documento define a estrutura do curso de inglês do Arthur.

O objetivo é organizar os conteúdos de forma progressiva, permitindo que o aluno evolua do nível iniciante até níveis mais avançados.

---

# Estrutura Geral

Arthur divide o aprendizado em trilhas.

Cada trilha possui aulas, exercícios, revisões e práticas de conversação.

---

# Trilha Geral

## Nível 0 - Primeiros Passos

Objetivo:

Fazer o aluno conseguir se apresentar em inglês.

Conteúdos:

- Alfabeto
- Pronúncia básica
- Greetings
- My name is
- I'm
- I'm from
- Nationalities
- Numbers
- Colors

Objetivo final:

O aluno consegue realizar uma apresentação simples.

---

## Nível 1 - Verb To Be

Conteúdos:

- Verb To Be
- Pronomes
- Perguntas simples
- Respostas curtas
- Profissões

Objetivo final:

O aluno consegue falar sobre si mesmo e fazer perguntas básicas.

---
