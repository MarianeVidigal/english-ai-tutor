# Workflow - Cadastro de Aluno

## Objetivo

Responsável por cadastrar novos alunos no banco de dados do projeto English AI Tutor.

---

## Entrada

- Nome
- Nível
- Objetivo
- Área
- Método de Aprendizagem
- SessionId

---

## Processamento

- Gerar IdAluno
- Registrar DataCadastro
- Definir Status = Ativo

---

## Saída

Cadastro realizado com sucesso.

Retorna IdAluno criado.
