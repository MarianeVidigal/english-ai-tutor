# WF - Extrair Perfil

## Objetivo

Realizar o cadastro completo de novos alunos.

---

## Responsabilidades

- Gerar IdAluno.
- Gerar Token.
- Gerar Código de Segurança.
- Salvar o cadastro.
- Retornar todas as informações do novo aluno.

---

## Entrada

Recebe:

- Nome
- Nível
- Objetivo
- Área
- Método

---

## Processamento

1. Gerar identificadores.
2. Criar cadastro.
3. Salvar na base de dados.
4. Retornar o perfil criado.

---

## Saída

Retorna:

- Perfil completo.
- Token.
- Código de Segurança.
