# WF - Salvar Progresso

## Objetivo

Atualizar a evolução do aluno ao final de um conteúdo concluído.

---

## Responsabilidades

- Atualizar Estado Atual.
- Atualizar Última Aula.
- Atualizar Total de Aulas.
- Atualizar Último Acesso.

---

## Entrada

Recebe:

- idAluno
- estadoAtual
- ultimaAula
- totalAulas

---

## Processamento

Atualiza as informações do aluno na base de dados.

---

## Banco de Dados

Google Sheets

Tabela:

Alunos

---

## Saída

Retorna:

```json
{
  "sucesso": true
}
```
