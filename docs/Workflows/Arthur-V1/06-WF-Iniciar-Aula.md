# WF - Iniciar Aula

## Objetivo

Preparar todas as informações necessárias para que o Professor Arthur possa iniciar uma aula personalizada.

---

## Responsabilidades

- Buscar o perfil completo do aluno.
- Organizar os dados.
- Validar o cadastro.
- Encaminhar o aluno para o Professor Arthur.

---

## Entrada

Recebe:

- Token

---

## Processamento

1. Buscar Perfil.
2. Validar cadastro.
3. Preparar os dados.
4. Chamar Professor Arthur.

---

## Saída

Primeira aula ou continuação da aula do aluno.

---

## Workflows relacionados

- WF - Buscar Perfil
- Professor Arthur
