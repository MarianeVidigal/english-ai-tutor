# WF - Buscar Perfil

## Objetivo

Localizar todas as informações cadastradas do aluno.

---

## Responsabilidades

- Buscar o aluno pelo Token.
- Retornar todos os dados cadastrados.

---

## Entrada

Recebe:

- Token

---

## Processamento

Consulta a base de dados.

---

## Saída

Retorna:

- IdAluno
- Token
- Código de Segurança
- Nome
- Nível
- Objetivo
- Área
- Método
- Estado Atual
- Última Aula
- Total de Aulas
- Idioma
- Versão do Perfil
