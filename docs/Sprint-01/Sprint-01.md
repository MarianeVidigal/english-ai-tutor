# Sprint 01 - Fundação do Arthur

## Objetivo da Sprint

Desenvolver a primeira versão funcional do Arthur, capaz de conhecer um novo aluno, criar seu perfil de aprendizagem e iniciar sua jornada no English AI Tutor.

Esta Sprint representa a fundação do projeto. Ao final dela, Arthur deverá ser capaz de realizar sua primeira interação de forma personalizada.

---

# Escopo

Nesta Sprint serão desenvolvidas as seguintes funcionalidades:

- [ ] Arthur realiza sua apresentação.
- [ ] Arthur explica como pode ajudar o aluno.
- [ ] Arthur entrevista um novo aluno.
- [ ] Arthur identifica o perfil do aluno.
- [ ] Arthur identifica os objetivos do aluno.
- [ ] Arthur identifica a forma preferida de aprendizagem.
- [ ] Arthur identifica o nível atual de inglês.
- [ ] Arthur cria um plano de estudos personalizado.
- [ ] Arthur salva todas as informações do aluno.
- [ ] Arthur inicia a primeira aula.

---

# Critérios de Conclusão

A Sprint será considerada concluída quando um novo usuário conseguir:

- conversar com Arthur pela primeira vez;
- responder às perguntas iniciais;
- receber um plano de estudos personalizado;
- iniciar sua primeira aula;
- ter seu perfil salvo para futuras conversas.

# Riscos Identificados

- Definir corretamente a estrutura de memória do aluno.
- Encontrar uma forma eficiente de identificar o nível de inglês.
- Projetar um fluxo flexível para diferentes objetivos de aprendizagem.
