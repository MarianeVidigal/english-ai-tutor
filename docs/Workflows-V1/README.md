# Workflows - Versão 1

Esta pasta documenta todos os workflows utilizados na primeira arquitetura do Arthur.

A Versão 1 foi desenvolvida inteiramente utilizando n8n e Inteligência Artificial.

Cada workflow possui uma responsabilidade específica dentro da arquitetura.

Esta documentação foi mantida para preservar a evolução do projeto mesmo após o início da Versão 2 em Python.

## Arquitetura
```
Arthur Core

↓

Autenticação / Cadastro

↓

Professor Arthur

↓

Salvar Progresso
```
