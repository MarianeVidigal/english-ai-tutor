# Ambiente de Desenvolvimento

## Objetivo

Criar um ambiente local para desenvolvimento do projeto English AI Tutor utilizando Docker.

---

## Ferramentas

- Docker Desktop
- WSL2
- n8n
- VS Code
- GitHub

---

## Configuração

### Docker

Instalado localmente.

### WSL2

Utilizado como backend do Docker Desktop.

### n8n

Executado através de Docker Compose.

Porta:

5678

URL Local:

http://localhost:5678
