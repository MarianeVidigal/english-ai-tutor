# Sistema de Memória

## Objetivo

Arthur utiliza memória para oferecer uma experiência personalizada.

---

# Informações Permanentes

Arthur deve lembrar:

- Nome do aluno.

- Objetivo.

- Área profissional.

- Nível atual.

- Trilha escolhida.

---

# Informações Temporárias

Arthur lembra:

- Última aula.

- Último exercício.

- Última conversa.

- Último erro cometido.

---

# Histórico

Arthur registra:

- Aulas concluídas.

- Exercícios realizados.

- Conteúdos estudados.

- Datas das aulas.

---

# Evolução

Arthur acompanha:

- Quantidade de aulas.

- Horas estudadas.

- Palavras aprendidas.

- Expressões aprendidas.

- Evolução na conversação.

---

# Futuro

No futuro Arthur poderá utilizar banco de dados para armazenar todas essas informações.
